# Vitality Vault

Vitality Vault is a Flutter app for logging sports activities, reviewing progress over time, and planning workouts with reminders. Activities and user data are stored locally on the device with SQLite, so the app works fully offline.

## Features

- **Activity logging** — record an activity's type (running, cycling, swimming, yoga, and 14 more), duration, and intensity (1–5). Calories burned are estimated from the activity's MET value, the chosen intensity, and the user's body weight.
- **Home overview** — activities are grouped into "This Week", "This Month", and "This Year", each showing total duration, total calories, and progress toward a duration goal per activity type.
- **Charts** — visual breakdowns of activity data (via Syncfusion Flutter Charts), filterable by time range.
- **Activity detail view** — a sortable history of every logged session for a given activity type.
- **Calendar & reminders** — plan workouts on a calendar and schedule local notifications to be reminded.
- **User profile** — store name, age, weight, and height; weight is used in the calorie calculation.
- **Motivational quotes** — a rotating quote carousel on the home screen, sourced from a bundled quote collection.

## Tech stack

- [Flutter](https://flutter.dev/) / Dart (SDK `>=3.3.1 <4.0.0`)
- [`provider`](https://pub.dev/packages/provider) — state management via `ChangeNotifier`
- [`sqflite`](https://pub.dev/packages/sqflite) — local SQLite persistence for activities and the user profile
- [`syncfusion_flutter_charts`](https://pub.dev/packages/syncfusion_flutter_charts) — activity charts
- [`table_calendar`](https://pub.dev/packages/table_calendar) — the planning calendar
- [`flutter_local_notifications`](https://pub.dev/packages/flutter_local_notifications) + [`timezone`](https://pub.dev/packages/timezone) — scheduled reminders
- [`carousel_slider`](https://pub.dev/packages/carousel_slider) — the quote carousel
- [`intl`](https://pub.dev/packages/intl) — date formatting

## Project structure

```
lib/
├── main.dart                     # App entry point, routes, ChangeNotifierProvider setup
├── models/                       # Plain data models (Activity, User)
├── providers/                    # ActivityProvider: SQLite access + app state
├── screens/                      # One file per screen (home, add activity, charts,
│                                  # activity detail, calendar, user profile)
└── helpers/                      # Supporting widgets/utilities (e.g. motivational quotes)
```

## Getting started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- A configured Android/iOS emulator, or a connected device

### Run the app

```bash
flutter pub get
flutter run
```

## Platform support

The project includes Android, iOS, Windows, macOS, and web platform folders generated by Flutter tooling, but development has focused on **Android**: local notifications are only wired up for Android, and the SQLite-backed storage layer is not configured for web. Other platforms may require additional setup before they run correctly.
